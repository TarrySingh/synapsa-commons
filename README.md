**This is the launch copy of Synapsa Commons.** The courses live, and are edited, starred and
discussed, in the main repository:
**[github.com/TarrySingh/Artificial-Intelligence-Deep-Learning-Machine-Learning-Tutorials](https://github.com/TarrySingh/Artificial-Intelligence-Deep-Learning-Machine-Learning-Tutorials)**

Binder and GitHub Codespaces copy the whole repository they start from, history included. The
main repository also carries the tutorials it has published since 2017, which makes it too large
for Binder to build at all. This copy holds only the courses, so both start in the time it takes
to install the lessons' packages. A workflow here pulls from the main repository every six hours;
anything edited here is overwritten.

[![Open in Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/TarrySingh/synapsa-commons)
